📚 Panduan Navigation Hub

File dokumentasi untuk menambahkan halaman baru ke sistem navigasi StickNext Rail Saga.

🚀 Quick Start - Cara Menambah Halaman Baru

Langkah 1: Buat File Halaman Baru

Buat file HTML baru dengan nama yang deskriptif (misal: video.html, blog.html)

Copy struktur dari about.html atau contact.html dan sesuaikan konten.

Langkah 2: Tambah Card ke pages.html

Buka pages.html dan tambahkan card baru dalam section yang sesuai:

<a href="halaman-baru.html" class="page-card" data-keywords="kata, kunci, pencarian">
    <div class="page-icon">🎥</div>
    <div class="page-title">Judul</div>
    <div class="page-desc">Deskripsi singkat</div>
</a>

Langkah 3: Pastikan Navigation Link Konsisten

Setiap halaman baru harus punya navbar dengan link ke pages.html:

<nav>
    <a href="index.html">Gallery</a>
    <a href="pages.html">Navigasi</a>
    <a href="about.html">Tentang</a>
    <a href="contact.html">Kontak</a>
</nav>
💡 Tips: Navigation link di halaman baru juga harus sama. Ini memastikan user bisa navigasi ke halaman manapun dari halaman manapun.

📋 Struktur Data Halaman

Atribut Card

  • href - URL halaman (required)
  • data-keywords - Keywords untuk search, dipisahkan koma
  • page-icon - Emoji atau icon (1-2 karakter)
  • page-title - Nama halaman (maksimal 2 kata)
  • page-desc - Deskripsi singkat (3-5 kata)

🎨 Struktur Section

Organizes halaman dalam kategori menggunakan section:

<section class="pages-section" data-category="nama-kategori">
    <h2>🔖 Nama Kategori</h2>
    <div class="pages-grid">
        <!-- Tambah cards di sini -->
    </div>
</section>
💡 Kategori yang ada: main, info, upcoming. Anda bisa menambah kategori baru sesuai kebutuhan.

📱 Responsive Design

Navigation Hub sudah fully responsive:

  • Desktop: Grid 6 kolom
  • Tablet: Grid 4-5 kolom
  • Mobile: Grid 2-3 kolom

Semua spacing dan ukuran font otomatis menyesuaikan dengan pengaturan dari settings.js.

🔍 Fitur Search

User bisa search halaman dengan:

  • Keyword dari atribut data-keywords
  • Nama halaman (page-title)
  • Deskripsi halaman (page-desc)

Contoh: User mengetik "foto" akan menampilkan semua halaman yang punya keyword "foto".

✨ Best Practices

  • ✅ Gunakan emoji yang relevan dan mudah dikenali
  • ✅ Judul halaman singkat dan deskriptif
  • ✅ Keywords banyak agar mudah dicari
  • ✅ Konsistent naming konvensi untuk file
  • ✅ Setiap halaman punya header dengan navbar lengkap
  • ✅ Gunakan settings.js agar tema konsisten
  • 🚫 Jangan ubah struktur CSS card yang ada
  • 🚫 Jangan ubah JavaScript search function
